# 도메인 문서

이 저장소는 단일 컨텍스트를 사용한다. 기능 범위와 화면 흐름을 확인할 때는
[README.md](../../README.md)의 관련 기능 및 프로젝트 구조를 확인한다.

화면 동작은 해당 `src/pages/` 컴포넌트와 `src/router/index.js`의 라우트를,
공유 상태는 관련 `src/stores/` 스토어를 확인한다. 백엔드 연동을 변경할 때는
`src/api/`의 관련 모듈과 백엔드의 API 계약 또는 실제 Controller·DTO를 확인한다.
인증·권한 변경에는 백엔드의 `docs/security.md`도 참조한다.

루트 `GLOSSARY.md`가 있으면 정의된 용어를 사용한다.
`docs/adr/`가 있으면 작업과 관련된 설계 결정만 읽는다.
제안이 기존 ADR과 충돌하면 해당 결정과 충돌 지점을 설명한다.
